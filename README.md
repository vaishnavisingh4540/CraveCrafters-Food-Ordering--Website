# 🍔 CraveCrafters – Food Ordering Website

CraveCrafters is a modern and responsive food ordering website designed to provide a simple and interactive food-ordering experience.

## ✨ Features

- 🍽️ Browse different food categories
- 🔍 Search and filter food items
- 🛒 Add multiple food items to the cart
- ➕ Increase item quantity
- ➖ Decrease item quantity
- 💰 Automatic subtotal and total calculation
- 🎉 Order confirmation
- 📱 Responsive design
- 🌙 Dark royal-themed interface
- 🚀 Deployed using GitHub Pages

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
